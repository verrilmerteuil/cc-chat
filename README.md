## ✨ Features

### 💬 Cross-Character Messaging
- Send and receive messages across all your characters
- Persistent chat history synced via cloud
- Real-time message delivery with WebSocket connection

### 👥 Contact Management
- Add contacts by player ID
- Favorite contacts for quick access
- Online/offline presence indicators with DND status
- Sort contacts alphabetically or by online status

### 📎 Attachments
- Share images in chat
- Built-in image preview with zoom controls (25%–100%)
- Download attachments directly to your system

### 🔗 Clickable Links
- HTTP/HTTPS links are automatically detected and clickable
- Security warning popup before opening external URLs
- Visual feedback with hover effects and link icons

### 📨 Tells Integration (Optional)
- Intercept and store in-game `/tell` messages
- Persistent Tell history with SQLite storage
- Tabbed UI with unread counters per sender
- Send Tells directly from the plugin interface

### 🔔 Notifications
- Customizable notification sounds (3 options)
- Window auto-open on new messages
- Blinking window indicator for unread messages
- Independent notification toggles for CCChat and Tells

### 🎨 Modern UI
- Clean, purple-themed interface
- Scalable font sizes (1.0x, 1.1x, 1.2x, 1.3x, 1.4x)
- Sharp text rendering at all scales
- Responsive layout with polished visuals

## 🚀 Getting Started

### Installation

1. Open the Dalamud Plugin Installer (`/xlplugins`)
2. Search for **CCChat**
3. Click **Install**

### Usage

- Use `/ccchat` or `/cc` to open the chat window
- Register an account or log in with your existing credentials
- Add contacts and start chatting!
